주별 내역

계정 · 서버 저장

로그인하면 기록이 서버에 저장돼서, 폰을 바꾸거나 브라우저가 비워져도 로그인만으로 전부 돌아와요. 로그인 전에도 이 기기에는 계속 저장됩니다.

주 단위 설정

주 시작 요일
한 주가 시작되는 요일이에요. 기본값은 수요일이고, 한 주는 시작 요일부터 7일 단위로 묶여요.
주간 인정 상한
일주일에 이 시간까지만 인정 누적에 셉니다. 실제로 일한 시간은 상한과 관계없이 전부 기록돼요.

저장 보호

상태를 확인하고 있어요

기록은 이 기기 안에 세 겹으로 저장돼요(기본 저장 + 스냅샷 + 보조 저장소). 하나가 지워지면 나머지로 자동 복구합니다. 그래도 브라우저 데이터 전체를 지우면 함께 사라지니, 백업 파일을 내보내 두는 게 가장 안전해요.

데이터

백업 파일은 어떤 상황에서도 되살릴 수 있는 최종 사본이에요. 기기를 바꾸기 전에 하나 내보내 두세요.

인정 시간이란?

실제 시간은 일한 그대로의 합계이고, 인정 시간은 주마다 상한(기본 30시간)까지만 센 합계예요. 예를 들어 한 주에 36시간 일하면 실제 누적에는 36시간이, 인정 누적에는 30시간만 쌓입니다. 기간별 누적도 같은 방식이라, 6개월·1년 누적이 상한을 반영해 계산돼요.

앱 설치

브라우저 메뉴에서 앱 설치 또는 홈 화면에 추가를 누르면 앱처럼 쓸 수 있어요. 오프라인에서도 열립니다.
