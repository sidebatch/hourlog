# 아워로그 (HourLog)

일한 시간을 기록하고 누적해서 보는 PWA.

**주소:** https://sidebatch.github.io/hourlog/

## 핵심 규칙

- **주 단위**: 기본은 수요일~화요일. 설정에서 주 시작 요일을 바꿀 수 있다.
- **이중 누적**:
  - **실제 시간** — 일한 그대로의 합계. "이번 주에 정말 얼마나 일했지?"에 답한다.
  - **인정 시간** — 주마다 상한(기본 30시간)까지만 센 합계. 초과분은 인정 누적에 쌓이지 않는다.
- **기간별 누적**: 최근 4주 / 3개월(13주) / 6개월(26주) / 1년(52주) / 전체. 모두 주 단위 구간이라 상한 계산이 정확하다.

## 기능

- 근무 기록 추가·수정·삭제 (출근-퇴근-휴게 입력, 또는 총 시간 직접 입력, 자정을 넘는 근무 지원)
- 홈: 이번 주 인정/실제, 전체 누적, 기간별 누적, 최근 기록
- 기록 탭: 월별 목록과 월 합계
- 통계 탭: 기간별 요약, 주별 차트(상한선 표시), 주별 내역(초과분 배지)
- 설정: 주 시작 요일, 주간 인정 상한, JSON 백업 내보내기/불러오기, 전체 삭제
- PWA: 홈 화면 설치, 오프라인 동작 (서비스 워커는 네트워크 우선)

## 기술

- 단일 `index.html` (인라인 CSS/JS), 데이터는 기기 `localStorage` 키 `hourlog-v1`에 저장
- v1.1.0 저장 보호: 영구 저장(persistent storage) 요청, 스냅샷 키(`hourlog-v1-backup`) + IndexedDB 보조 사본, 로드 시 자동 복구, 백업 미실시/30일 경과 시 홈 배너 알림. 단, 브라우저 데이터 전체 삭제는 막을 수 없어 JSON 백업 내보내기가 최종 안전장치다
- v1.2.0 저장 무결성: 저장 직전 저장소와 병합(다른 창의 낡은 상태가 새 기록을 지우지 못함, 삭제는 `deletedIds` 삭제로 전파), 쓰기 후 되읽기 검증 + 실패 시 화면 경고, pagehide/숨김 시 현재 상태 재저장(게임 방식), 설정에 저장 상태 진단(기록 수·마지막 저장·검증 결과·오리진 사용량) 표시. 병합·삭제·쓰기 실패 테스트 16개 PASS
- v1.3.0 서버 동기화: One Phrase와 같은 Supabase 프로젝트에 `hourlog_entries`·`hourlog_settings` 테이블 (설정 SQL은 `supabase-setup.sql`, 대시보드에서 1회 실행). Google 로그인 시 로컬과 서버를 병합(합집합 − 삭제 표시)해 거울 동기화하고, 이후 저장은 자동 푸시. 로컬 우선이라 오프라인·미로그인 상태에서도 기존처럼 동작. 동기화 병합 테스트 12개 + 저장 회귀 4개 PASS
- 시간은 내부적으로 분(minute) 단위 정수로 계산해 소수 오차를 피한다
- 핵심 로직(주 시작 계산, 상한 적용)은 단위 테스트로 검증함
